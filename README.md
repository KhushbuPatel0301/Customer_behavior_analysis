# Customer_behavior_analysis

## Project Overview

This project analyzes **customer purchasing behavior** to identify trends in sales, revenue, customer segments, subscriptions, discounts, product performance, and demographics.

The project follows an end-to-end data analytics workflow:

**Raw Data → Python Data Cleaning → MySQL/SQL Analysis → Power BI Dashboard → Business Insights**

The goal is to transform raw customer data into meaningful insights that can support data-driven business decisions.

---

## Project Objectives

* Clean and prepare customer data for analysis.
* Analyze purchasing behavior using SQL.
* Identify revenue and sales trends across product categories.
* Compare customer behavior across age groups and genders.
* Analyze subscription and discount behavior.
* Segment customers based on previous purchases.
* Identify top-performing products and product ratings.
* Build an interactive Power BI dashboard.

## Project Workflow

### 1. Data Cleaning – Python

The raw customer dataset was cleaned and prepared using Python and Pandas.

Key steps included:

* Data quality checks
* Data type validation
* Handling data inconsistencies
* Preparing an analysis-ready dataset

### 2. SQL Analysis – MySQL

The cleaned data was imported into MySQL and analyzed using SQL queries.

Key business questions included:

* What is the total revenue generated by male and female customers?
* Which discounted customers spend more than the average purchase amount?
* Which products have the highest average review ratings?
* How does spending differ between Standard and Express shipping?
* Do subscribed customers spend more than non-subscribers?
* Which products have the highest discount rates?
* How many customers are New, Returning, or Loyal?
* Which products are most frequently purchased within each category?
* Are repeat buyers more likely to subscribe?
* Which age groups contribute the most revenue?

### 3. Power BI Dashboard

An interactive Power BI dashboard was developed to communicate the key findings.

The dashboard includes:

* Total Number of Customers
* Average Purchase Amount
* Average Review Rating
* Subscription Status
* Revenue by Category
* Sales by Category
* Revenue by Age Group
* Sales by Age Group
* Interactive filters for Gender, Category, Subscription Status, and Shipping Type

---

## Key Insights

The analysis identified several customer behavior patterns:

* **3K+ customers** were analyzed.
* The average purchase amount was **$59.51**.
* The average review rating was **3.75**.
* **27.41%** of customers were subscribed, while **72.59%** were non-subscribed.
* **Clothing** generated the highest revenue among the analyzed categories.
* Customer revenue and purchasing behavior varied across different age groups.

---

## Business Recommendations

Based on the analysis, businesses can:

* Focus marketing efforts on high-revenue product categories.
* Develop targeted campaigns to increase subscription adoption.
* Create personalized offers for returning and loyal customers.
* Use demographic insights for targeted marketing.
* Monitor product ratings and customer feedback to improve customer satisfaction.
* Evaluate discount strategies to balance customer engagement and revenue.
